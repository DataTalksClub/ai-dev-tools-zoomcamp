# NIST Secure Software Development Framework 1.1

Locator: https://csrc.nist.gov/projects/ssdf

Summary: SSDF is direct precedent for teaching secure-development outcomes independently of particular tooling.

- [FACT nist-ssdf] SSDF is a set of fundamental secure software development practices intended for integration into different SDLC implementations.
- [FACT nist-ssdf] Its practices are outcome-based and its implementation examples are illustrative, not required or exhaustive.
- [FACT nist-ssdf] The framework aims to reduce introduced vulnerabilities, limit the impact of undiscovered vulnerabilities, and address root causes to prevent recurrence.
- [INFERENCE nist-ssdf] Module 4 can use the same pattern: durable practice, evidence of completion, then interchangeable implementation examples.

Limitations: SSDF addresses software producers broadly and is not specifically a coding-agent operations curriculum.
