# OWASP Secure Code Review Cheat Sheet

Locator: https://cheatsheetseries.owasp.org/cheatsheets/Secure_Code_Review_Cheat_Sheet.html

Summary: Secure review combines application context, threat focus, automated findings, and manual analysis of logic that scanners cannot settle.

- [FACT owasp-secure-code-review] Preparation includes architecture, business requirements, threat models, security findings, assets, and high-risk functions.
- [FACT owasp-secure-code-review] Diff-based review identifies changed components, impact on controls, purpose, and high-risk modifications.
- [FACT owasp-secure-code-review] Automated findings should prioritize manual review; business logic, authorization, state transitions, and control effectiveness require manual analysis.
- [INFERENCE owasp-secure-code-review] An agent can assemble context and propose findings, but a strong lab needs an explicit claim-evidence-decision record.

Limitations: The cheat sheet is extensive and web-application-centric; Module 4 should select a small consistent review procedure.
