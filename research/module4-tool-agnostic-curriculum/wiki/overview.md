# Overview

- [HUMAN] Redesign Module 4 around durable concepts that work with Codex, Claude Code, and comparable terminal agents, including headless workflows.
- [FACT current-module-4,syllabus-proposal] The current curriculum already contains strong verification, approval, evidence, and governance principles, but packages them as seven named-tool lessons.
- [INFERENCE nist-csf-2,nist-ssdf,current-module-4] The module should specify security and operational outcomes first, require portable evidence artifacts second, and present products only as interchangeable implementation examples.
- [INFERENCE current-module-4,syllabus-proposal,tool-repositories] A common control loop unifies the module: scope, collect evidence, analyze, propose, approve, act, verify, and record.
- [HUMAN] The narrowed module now extends the Module 2 app through OpenTelemetry observability, actionable alerts, agent-first incident response with human escalation, and recurring multi-model security audits.
- [INFERENCE observability-pipeline,alerting-sre,safe-remediation] The central course system is telemetry-to-alert-to-bounded-response, with auditability across every transition.
